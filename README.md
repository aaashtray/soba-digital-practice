# SOBA · Digital практика

Мобильный тренажёр для курса digital-стратегии: 11 миссий, 44 упражнения. Выбор одного ответа, заполнение пропуска, поиск лишнего и сопоставление трёх пар. После ошибки доступны подсказка и новая попытка; после верного ответа — объяснение. В конце миссии можно повторить упражнения, вызвавшие трудности.

Пройденные миссии сохраняются только в браузере устройства. Аккаунтов студентов, отправки результатов преподавателю и общей базы нет. При недоступном хранилище прогресс остаётся в текущей сессии. Выйти из незавершённой миссии можно в любой момент; ответы внутри неё при возвращении начинаются заново.

## Рабочая структура

Это тематическое деление прототипа, а не утверждённое расписание занятий. Семь предложенных блоков усиления курса не заменяют фундаментальные темы. Для проверки формата они развёрнуты в 11 миссий:

| Миссия | Основа и решение |
|---|---|
| 1. От задачи к стратегии | Лекция 1, каскад и De’Longhi; маркетинговая, коммуникационная и медийная задачи |
| 2. Исследование с выводом | Лекция 2, конкуренты, OKKO/ПИК; решения на основе анализа |
| 3. Люди, сегменты и CJM | Лекция 3; различие сегмента и таргетинга, интервью о поведении |
| 4. Поведение и путь к покупке | Лекция 6; мотивы, барьеры, контекст выбора, упражнение про очки |
| 5. Роли и связка каналов | Brandformance, лекция 8; media, content, performance, influencers |
| 6. Performance и гипотезы | Лекция 7; HADI, A/B, качество трафика и конечное действие |
| 7. KPI и измерение | Лекция о метриках; обновлённое различение атрибуции и причинного эффекта |
| 8. Медиаплан без магии | Новая практика, опирающаяся на охват и частоту из лекции 8 |
| 9. Бюджет и альтернативы | Новый блок: расчёты, ограничения, сценарии |
| 10. Флайтинг и оптимизация | Расширение архитектуры кампаний; календарь, зависимости и правила пересмотра |
| 11. Защита digital-тактики | Переработка материалов о тендерах под обоснование решений |

Самостоятельное обучение кабинетам, подробная семантика, продажи агентских услуг и отдельная AI-лекция не входят в согласованный фокус. Коммуникация, экосистема каналов и управление реализацией встроены в соответствующие миссии. Число встреч и окончательная нумерация требуют согласования с преподавателем.

## Контент

Все тексты упражнений написаны заново. Презентации, студенческие интервью, исходные таблицы, личные материалы и фотографии в репозиторий не включены. Упоминания De’Longhi и OKKO обозначены как разборы принципов из лекций, а не новые доказательства коммерческих результатов.

BURGER GO — вымышленная глобальная сеть фастфуда; QADAM — вымышленный сервис коротких поездок в Алматы; DROP — вымышленный магазин одежды и кроссовок. Ситуации и числа учебные. Ставки и прогнозы не являются данными рынка Казахстана. Медиапланирование проверяет принципы и расчётные зависимости, а не единственно правильный канал или универсальный бюджетный сплит.

Исторические спорные утверждения не перенесены как правила: средняя частота не равна частоте каждого человека, атрибуция не доказывает инкрементальность, корреляция не доказывает причинность, фиксированный порог корреляции не определяет пригодность KPI.

## Оформление

Палитра школы проверена по https://soba.education и презентациям: чёрный, белый, жёлтый (#f7ec14 на сайте). В текущем CSS сайта школы указан Inter; здесь по пожеланию преподавателя использован стек Helvetica, Arial, sans-serif. Логотип изображением не воспроизводится: используется текстовое имя SOBA / School of Business Adaptation.

## Разработка и проверки

Node 22.13+; npm install; npm run dev; npm run build. Контент: lib/course.ts. Интерфейс: app/page.tsx. Проверка типов: npx tsc --noEmit. Проверки контента и расчётов: node --experimental-strip-types --test tests/course.test.mjs.

WebMCP при поддержке браузером предоставляет чтение состояния, открытие миссии, проверку ответа и переход дальше. При отсутствии API обычный интерфейс работает независимо. Наличие API и поведение в поддерживаемом WebMCP-контексте отдельно не проверены.
